# Fintools Find — Institutional-Grade Financial Calculators

Fintools Find is a high-speed, ad-supported digital platform offering 28 active, interactive financial calculators across **Loans**, **Investment**, **Tax**, and **Retirement**.

Built with **Astro 4.x**, **Preact**, **Tailwind CSS**, and **Vitest**, Fintools Find guarantees **100% client-side data privacy** where zero user inputs are saved or transmitted to external servers.

## 🛠️ Technology Stack

- **Framework**: [Astro 4.x](https://astro.build/) (Static Output Mode)
- **UI Components**: [Preact](https://preactjs.com/) for interactive widgets
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with modern design system tokens
- **Testing**: [Vitest](https://vitest.dev/) (31 Test Suites / 63 Unit Tests)
- **Deployment Target**: Cloudflare Pages / Static Edge CDN

## 💻 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone git@github.com:mahboobkabari/fintools-find.git
   cd fintools-find
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:4321` in your browser.

4. **Run unit test suite**:
   ```bash
   npm test
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```

---

## 🔐 100% Client-Side Privacy Guarantee

All financial calculations execute 100% within the user's web browser JavaScript DOM. No salary figures, loan numbers, tax inputs, or personal identifying data are ever transmitted or saved to remote databases.
